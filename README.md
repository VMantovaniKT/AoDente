<h1>Ao Dente 👨‍🍳 </h1> 

Meu primeiro projeto no Android Studio! 🚀

Desenvolvi um aplicativo de seleção aleatória de culinárias para ajudar quem está em dúvida sobre o que comer. A ideia é simples: com um toque, o app te dá sugestões de culinárias do mundo todo! 😋

🔧 Tecnologias utilizadas:

- Kotlin como linguagem principal
- Jetpack Compose para criar uma interface moderna, fluida e responsiva
- Android Studio como ambiente de desenvolvimento

Esse foi um projeto 100% autoral, onde pude colocar em prática tudo o que venho estudando sobre desenvolvimento mobile e UI/UX no Instituto PROA 💙. Também foi uma ótima forma de exercitar lógica, organização e boas práticas de código.
